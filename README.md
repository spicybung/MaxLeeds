# MaxLeeds

3DSMax scripts for R* Leeds file formats. The current iteration supports Autodesk 2010-2024. If you actually want to "do it 100% like Rockstar Games" I suggest you download 3DSMax '06 or '07 and get ready to cry because there's no support.
